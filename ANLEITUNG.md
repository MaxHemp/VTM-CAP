# So starten Sie VTM Studio (3 Schritte)

1. Legen Sie Ihre entpackten Claude-Design-Dateien in den Ordner `design`
   (die Datei BITTE-ERSETZEN.txt dort loeschen).
2. Laden Sie den kompletten Inhalt dieses Ordners in Ihr GitHub-Repository hoch
   (github.com, gruener Button "New", dann "uploading an existing file",
   alles per Maus in das Fenster ziehen, unten "Commit changes" klicken).
3. Verbinden Sie das Repository mit Claude Code im Browser und schreiben Sie:
   "Lies PROMPT_Claude_Code_VTM_Studio.md und setze den Auftrag um.
   Beginne mit dem Plan fuer Meilenstein M1 und eroeffne dafuer einen Pull Request."
